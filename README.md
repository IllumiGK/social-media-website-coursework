# Social Media Web Application

A full-stack social media web application built as a coursework project using Node.js for backend logic and vanilla JavaScript for frontend interactivity.

---

## 🚀 Features

- User interaction system with dynamic frontend updates
- Backend routing system built with Node.js
- Structured JSON-based data handling between frontend and backend
- Basic post/request handling system
- Interactive UI built with HTML, CSS, and JavaScript
- API testing and validation using Postman

---

## 🧠 Key Concepts

- Client-server architecture
- Backend routing and request handling
- JSON data exchange
- DOM manipulation for dynamic UI updates
- Basic full-stack application structure

---

## 🛠 Tech Stack

- Node.js
- JavaScript
- HTML5
- CSS3
- JSON
- Postman
